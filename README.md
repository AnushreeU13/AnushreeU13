## 🛠️ Portfolio & Highlighted Projects

- 🏎️ **[Mercedes F1 Team Infringement Profiling](https://github.com/AnushreeU13/Mercedes-Infringement-Profiling.git)** - *NLP*: Built and evaluated automatic summarization pipelines over FIA Mercedes F1 infringement documents. Experimented with extractive (TextRank, LexRank) and abstractive (DistilBART, Pegasus) models, comparing them against LLM-generated ground truth using ROUGE scores and intrinsic metrics.
- 💳 **[Credit Risk Analysis for Synchrony](https://github.com/AnushreeU13/Credit-Risk-Analysis-for-Synchrony)** - *Machine Learning / Predictive Modeling*: Developed a machine learning pipeline using a **Random Forest Regressor** to forecast Q4 customer transaction spending. Grouped accounts into advanced risk classifications (Low Risk, Watchlist, High Risk) by assessing credit bureau scores and anomalies, and engineered a model to recommend personalized credit line increases.
- 🖼️ **[Experimenting Multimodal "Cloze" in Comics](https://github.com/AnushreeU13/Experimenting-Multimodal-Cloze-in-Comics-with-Vision-Language-Model)** - *Vision-Language Models / Generative AI*: Explored Narrative Closure in AI using the **LLaVA-OneVision Multimodal Large Language Model**. Modeled a system capable of analyzing sequential comic panels to logically predict and describe missing panels ("the gutter"), effectively recreating standard narratives visually using **Stable Diffusion v1.5** fine-tuned with a "Silver Standard" dataset created via Google Gemini.
- 🏁 **[Formula One Logistics for Red Bull Racing](https://github.com/AnushreeU13/Formula-One-Logistics-for-Red-Bull-Racing)** - *Monte Carlo Simulation and risk prediction*: A robust simulation tracking the complexities of transporting critical F1 cargo between race tracks across continents under tight turnaround windows (58-65 hours). Implemented randomized logic with PERT distributions to evaluate variables like road vs. air transport, crash recovery, breakdowns, and external disturbances to optimize supply chain resilience.
