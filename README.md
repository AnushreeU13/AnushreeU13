## 🚀 Live Projects & Under Development

### 🧬 [ScholarBOT](https://github.com/AnushreeU13/ScholarBOT)
**NLP | RAG | AI Guardrails | Responsible AI**
A specialized physician's tool for querying domain-specific knowledge bases with a focus on **zero-hallucination** performance.
- **Precision First**: Implements strict confidence thresholds; abstains from answering if evidence is insufficient.
- **Dual Summarization**: Automatically generates both technical **Clinician Summaries** and accessible **Patient-Friendly Summaries**.
- **Interactive Retrieval**: Users can upload custom documents for real-time RAG-based interrogation.
- **Tech Stack**: GPT-4o, Llama (via Groq), RAGAS for evaluation, and custom Guardrail logic.

### 🛡️ [PACT (Privacy-Aware Communication Tool)](https://github.com/AnushreeU13/PACT)
**Privacy Engineering | spacy | scispacy | Llama-3.1-8B**
A critical middleware layer between users and LLMs designed to prevent digital footprint leakage.
- **Contextual Redaction**: Dynamically identifies and masks sensitive data (Names, Locations, Financials, Health info) before it reaches the model.
- **Configurable Privacy**: Allows users to set granular redaction preferences depending on the sensitivity of the task.
- **Intelligent Processing**: Utilizes Llama-3.1-8B and specialized scispacy models for high-accuracy NER in medical and financial contexts.

## 🛠️ Portfolio & Highlighted Projects

### 1. 🖼️ [Experimenting Multimodal "Cloze" in Comics](https://github.com/AnushreeU13/Experimenting-Multimodal-Cloze-in-Comics-with-Vision-Language-Model)
**Vision-Language Models | Generative AI**
Explored **Narrative Closure** using the LLaVA-OneVision MLLM. Modeled a system capable of analyzing sequential comic panels to logically predict and describe missing panels ("the gutter"), recreating narratives visually using **Stable Diffusion v1.5** fine-tuned on Gemini-generated "Silver Standard" datasets.

### 2. 🏁 [Formula One Logistics for Red Bull Racing](https://github.com/AnushreeU13/Formula-One-Logistics-for-Red-Bull-Racing)
**Monte Carlo Simulation | Risk Prediction**
A robust simulation tracking the complexities of transporting critical F1 cargo across continents within tight turnaround windows (58-65 hours). Implemented randomized logic with **PERT distributions** to optimize supply chain resilience against crashes, breakdowns, and external disruptions.

### 3. 🏎️ [Mercedes F1 Team Infringement Profiling](https://github.com/AnushreeU13/Mercedes-Infringement-Profiling.git)
**Large Language Models | NLP | Automated Evaluation**
Built automated summarization pipelines for FIA Mercedes F1 infringement documents. Leveraged **Groq and GPT-4o** to generate silver-standard ground truths for evaluating extractive (TextRank) vs. abstractive models using ROUGE scores and semantic similarity.

### 4. 💳 [Credit Risk Analysis for Synchrony](https://github.com/AnushreeU13/Credit-Risk-Analysis-for-Synchrony)
**Predictive Modeling | Random Forest**
Developed a machine learning pipeline to forecast Q4 customer spending. Implemented an advanced classification system (Low Risk, Watchlist, High Risk) based on credit bureau score anomalies and engineered features to recommend personalized credit line increases.

### 5. 📊 [Synchrony Intraday Call Forecasting](https://github.com/AnushreeU13/Synchrony_Intraday_Call_Forecasting)
**Time-Series Analysis | LightGBM | Regression**
A high-precision forecasting tool for call center operations (4 centers, 30-minute intervals).
- **Advanced Post-Processing**: Anchored model predictions to daily totals using a **40% Trimmed Mean** approach to eliminate outlier influence.
- **Asymmetric Optimization**: Utilized Quantile Regression to minimize penalties associated with under-prediction.
